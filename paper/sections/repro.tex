\section{Reproducibility}
\label{sec:repro}

The code, the manual data files with their sources, the dated raw snapshots, every intermediate and result table and the dashboard are in the repository accompanying this paper (commit \commitHash). The analysis runs in Docker with R \Rversion{} (\texttt{sf} \versf, \texttt{spatstat} \verspatstat, \texttt{spdep} \verspdep, \texttt{spatialreg} \verspatialreg, \texttt{MASS} \verMASS), Python 3.12 and PostGIS 16; package versions are pinned in \texttt{renv.lock} and \texttt{requirements.txt}. Python scripts in \texttt{pipeline/} collect the data, R scripts in \texttt{analysis/} build the areas and run the analysis, and \texttt{run\_all.sh} runs every step in order. The Wikidata snapshot is dated \snapshotDate; rerunning the queries on a later date gives a different snapshot, so the cached snapshot is the reference. Every simulation and permutation uses the seed \seed. The season rule has unit tests, and the dashboard has output tests. Every number, table and figure in this paper is generated by \texttt{analysis/paper/11\_paper\_inputs.R} from the cached outputs, without refitting, and every reference is checked against Crossref or its official page by \texttt{paper/verify\_refs.py}. An interactive dashboard (\texttt{app/}) shows the maps, models and country tables.
